02 / Architecture

四模块系统架构

Hazard → Exposure → Vulnerability → Financial

这是国际再保险行业通用的 CAT 模型标准流水线。每个模块的输出即下一模块的输入，形成从气象物理量到资本决策数字的完整传导链。

每层左侧色条对应模块编号；蓝色箭头标注模块间传递的数据对象。 visualization.py 横切四个模块，统一产出 11 张 300 dpi 英文图表； main.py 负责流程编排与全局一致性审查。

typhoon_cat_model/ ├── config.py # 全局参数 dataclass：Hazard / Stochastic / Vulnerability / Financial / Plot ├── hazard.py # 模块 A：真实路径、Holland 风场、登陆衰减、随机事件集 ├── exposure.py # 模块 B：14 地市暴露数据库 ├── vulnerability.py # 模块 C：Emanuel / 对数正态复合曲线、内涝与需求激增、校准 ├── financial.py # 模块 D：EP 曲线、资本、再保分层、CAT bond、基差风险、组合 ├── visualization.py # 11 张 300dpi 英文图表 ├── main.py # 主流程编排 + 全局一致性审查（IS_PASS） ├── tests/ # 19 项独立校验（test_validation.py） ├── outputs/ # fig01 ~ fig11 png └── docs/ # 本展示页（GitHub Pages）
03 / Methodology

模块详解与核心公式

Governing equations of each module

所有公式均取自公开文献的标准形式；参数取值见 config.py，随机种子固定以保证复现性。

A

Hazard · 灾害强度场

Parametric wind field & stochastic event set
hazard.py

以中心气压差 Δp 为驱动量，通过解析风廓线还原台风每一时刻的二维风场，再叠加移动非对称与登陆衰减修正，最终对 14 个暴露点取逐点最大阵风风速。

核心公式

最大风速—气压差关系（Atkinson & Holliday 1977，西北太平洋） Vmax = 3.4 · Δp0.644
Holland B 参数（物理量，保证廓线与强度自洽，截断至 [0.8, 2.5]） B = ρ · e · Vg2 / Δp　　(ρ = 1.15 kg/m³, e = 2.718, Vg ≈ Vmax)
Holland (1980) 梯度风廓线 Vg(r) = √( B/ρ · Δp · (Rmw/r)B · exp(−(Rmw/r)B) + (r·f/2)2 ) − r·f/2
最大风速半径（Willoughby & Rahn 2004） Rmw = 46.4 · exp(−0.0155 · Vmax + 0.0169 · |φ|)　[km]
登陆后指数衰减（Kaplan & DeMaria 1995） Vmax(t) = V0 · exp(−αdec · (t − tlandfall))　　αdec ≈ 0.095 / hr

关键处理

  • 移动非对称修正：台风右半圆叠加 α · Vmove（前向切变），α ≈ 0.4。
  • 地表 / 阵风换算：梯度风 → 地表风 × 0.85，地表风 → 阵风 × 1.30。
  • 随机事件集：年频率服从泊松分布 λ = 3.2；Δp 由截断对数正态抽样（中位 26 hPa，σ = 0.52，截断区间 [8, 105] hPa）；登陆点纬度在 [25.5°N, 38.0°N] 均匀分布；移动方向与移速取自经验分布。共 10,000 场事件，随机种子 20190810。

对应图表：fig01 路径图 · fig02 风廓线 · fig03 风场热图 · fig11 事件集诊断

B

Exposure · 暴露资本存量

Regional exposure database, 14 prefecture-level cities
exposure.py

暴露口径为「区域风灾可暴露资本存量」，由地市 GDP 经资本产出比放大、再按可受风灾影响的资本占比折减得到；保险口径再乘以保险渗透率。

核心公式

经济暴露值 exposed_value = GDP × capital_output_ratio (3.2) × wind_exposed_fraction (0.45)
保险暴露值 insured_value = exposed_value × insurance_penetration

关键处理

  • 覆盖 14 个华东沿海地市（浙江 / 江苏 / 上海 / 山东），台州已扣除温岭部分以避免重复计算。
  • 每个地市配置 4 类建筑权重：混凝土 concrete、砌体 masonry、轻钢 light steel、温室大棚 greenhouse，用于加权合成脆弱性曲线。
  • 保险渗透率与省份易涝系数逐市配置，体现区域差异。

对应图表：fig05 分城市损失校验

C

Vulnerability · 脆弱性与损失校准

Damage functions, secondary perils & brentq calibration
vulnerability.py

把风速映射为损失率，是整个链路中不确定性最大、也最需要校准的一环。本模块采用两族标准损伤函数加权合成，再叠加次生内涝与灾后需求激增两个放大因子。

核心公式

Emanuel (2011) 三次方损伤函数 f(v) = (v / vhalf)3 / ( 1 + (v / vhalf)3 )
对数正态损伤函数（β ≈ 0.44） f(v) = Φ( ln(v / vhalf) / β )
建筑类型加权复合曲线 fcomp(v) = Σi wi · fi(v)
次生内涝放大因子（高斯随到路径距离衰减） 1 + g(distance) · (Vmax / Vref) · province_susceptibility

关键处理

  • 省份易涝系数：浙江 1.2 / 山东 1.3 / 江苏 0.9 / 上海 0.8。
  • 需求激增因子（demand surge）：灾后重建价格膨胀，约 +8%。
  • 校准：用 scipy.optimize.brentq 反演 v_half（≈ 176 m/s），使利奇马经济建模损失精确等于实际的 537.2 亿元。
    ⚠ 该标定值不具物理可解释性，详见 局限性声明。

对应图表：fig04 脆弱性曲线族 · fig05 分城市校验

D

Financial · 风险融资与定价

EP curves, regulatory capital, XoL layers & CAT bond pricing
financial.py

把 10,000 场事件损失转成年损失表（YLT），进而生成整套可直接用于资本与定价决策的指标。这是从「风险量化」跨到「风险定价」的关键一步。

EP 曲线与资本

年均损失与超越概率曲线 AAL = Σ lossi · Pi　|　OEP：单事件最大损失超越概率　|　AEP：年聚合损失超越概率
尾部风险与偿二代二期（C-ROSS II）巨灾资本 TVaRp = E[ L | L ≥ VaRp ]　　Capital = VaR99.5% − AAL

超赔再保险分层（Excess of Loss）

标准差保费原理（k 按层位递增，e 为附加费用率） P = ( E[R] + k · σR ) · ( 1 + e )　　ROL = Premium / Limit

CAT Bond 定价

Lane (2000) 多因子 spread 模型 Spread = EL + γ · PFLα · CELβ EL 期望损失 · PFL 本金损失概率 · CEL 条件期望损失
Wang (2000/2002) 畸变算子定价 F*(x) = Φ( Φ−1(F(x)) − λ )，再对畸变分布取期望

基差风险与投资组合

对冲效率（q 为最优对冲名义比例） HE = 1 − Var( L − q · P ) / Var( L )
  • 触发结构对比：赔偿/指数触发（indemnity / index）vs 参数触发（parametric cat-in-a-box）。
  • 箱体设计：naive cat-in-a-box 与 fitted-box（按登陆纬度分箱条件平均损失）对照，量化触发结构设计的价值。
  • 投资组合：网格法求有效前沿 + 最大夏普组合，衡量零贝塔 CAT bond 的分散化价值。

05 / Climate

气候变化情景分析

IPCC AR6 WG1 Ch11 / Knutson et al. (2020) scenario scaling

模块 climate.py 在既有四模块之上叠加气候情景引擎，用共同随机数扰动保持事件几何不变、仅变换强度维度，使情景对比更干净。

核心发现：在 SSP5-8.5 2050 情景下，百年一遇经济损失的总漂移为 +161.5%；其中恒定 2020 暴露口径的纯气候信号为 +48.4%，暴露增长贡献 +76.7%，气候与暴露的交互项约占 23%。这说明：损失上升不能简单归因于"气候变暖"或"沿海财富堆积"中的任何一方，而是两者的非线性叠加。

金融传导（恒定 2020 暴露口径）

再保险与 CAT bond 的利差漂移不宜混入暴露增长——因为合约期限（1~3 年）远短于暴露增长周期，续转时会通过重新定价自动吸收。真正需要"今天定价进去"的是气候信号。

  • 2020 年百年一遇损失，在 SSP5-8.5 2050 下约贬值为 47 年一遇。
  • 按 2020 结构重估的 CAT bond Lane 利差需上移 +217 bp。
  • 再保险三层期望损失率分别漂移 +44% / +73% / +107%。
重要提示：本模块使用截断对数正态强度分布，尾薄于真实潜在强度约束；Δp 中位数上移已使 Cat 4+ 事件占比漂移约 +134%，远高于 Knutson et al. (2020) 的 +13%。因此情景尾部应作为气候压力测试而非中性预测使用。

研究点：Lane 591 bp vs Wang 268 bp —— 巨灾风险溢价之谜的实证入口

同一份风险敞口、同一套 EP 曲线，两种主流定价方法给出的 spread 相差 2.2 倍： Lane (2000) 591 bp 是对真实市场成交价的多因子经验拟合， Wang (2000) 268 bp 则是在无套利与风险中性测度变换框架下的理论一致定价。

这个缺口不是模型 bug，而是巨灾风险融资领域长期存在的 「巨灾风险溢价之谜」（cat risk premium puzzle）： CAT bond 的市场 spread 系统性地高于纯精算期望损失所能解释的水平，通常是 EL 的数倍。 主流解释包括投资者对模糊性厌恶（ambiguity aversion）——巨灾模型本身的参数不确定性被单独定价； 市场分割与资本约束——ILS 市场专业投资者有限，供给弹性不足； 以及尾部厌恶与新颖性溢价。

本项目把两条定价路径并置在同一份数据上，使这个缺口可测量、可分解、可做敏感性分析 （见 fig08），从而为「溢价究竟来自何处」提供一个可复现的实证起点。 这也是本模型在教学与研究场景下最有延展价值的接口。

07 / Limitations

局限性声明

Scope, assumptions and misuse warnings

请在引用任何数字之前先读完本节。本项目定位为可运行的方法学教学与工程骨架，不是生产级精算模型。

关键防误用提示（务必阅读）

标定 Vhalf ≈ 176 m/s 不具备物理可解释性。 为匹配利奇马 537.2 亿元的区域总损失，brentq 反演得到的 v_half 高达约 176 m/s， 远高于 Emanuel (2011) 在大西洋单栋建筑上标定的 74.7 m/s。

其本质是：本模型的损失分母是「区域风灾可暴露资本存量」（GDP × 资本产出比 × 风灾暴露占比）， 而非单栋建筑的重置成本。因此 v_half 在这里只是一个让复合脆弱性曲线在该口径下匹配总损失的 尺度参数（scaling parameter），并不描述真实的「风速 → 建筑损毁」物理关系。

后果：该曲线不可直接用于单体建筑或保单级定价。 若要做单栋建筑定价，必须改用重置成本口径的暴露数据（逐建筑重置价值，而非 GDP 口径资本存量） 重新标定 v_half 与建筑类型权重，否则会系统性高估风速—损失敏感性。

其他局限

  1. 示例数据，非真实理赔校准：暴露数据库为 14 地市公开 GDP 估算的示例值；脆弱性曲线由利奇马单一事件反演，未使用实际保险理赔损失数据拟合，仅用于演示方法学链路。
  2. 风场为解析模型：采用 Holland 1980 解析廓线 + 经验非对称/衰减修正，未接入 ERA5 / CMA 再分析风场或数值模式输出；近岸精细化风场（地形、海陆风）未建模。
  3. 路径简化：利奇马真实路径为 37 点折线；随机事件集用经验分布抽样，未做完整气候态生成（genesis density / track density 统计建模）。
  4. 暴露—损失聚合层级偏粗：城市级点暴露 + 逐点最大风速近似，未做网格化微地形暴露分布。
  5. 金融模块为方法论演示：再保分层/资本/CAT bond 参数（k、e、γ、α、β、λ）均为行业经验取值，非特定公司精算假设；基差风险与投资组合为简化双/多资产演示。
  6. 单一 peril：仅建模台风风灾直接损失 + 次生内涝，未含风暴潮、独立洪涝模块或业务中断（BI）链条。
  7. 气候变化为压力测试：模块 E 按 Knutson 2°C 锚点线性缩放，并在薄尾截断对数正态下产生偏激进的强台风尾部放大；情景数字应作为压力测试而非费率预测使用。未包含海平面上升、风暴潮淹没与 Kossin (2018) 移速减慢等二次效应。
07 / Reproduce

如何运行

Clone, install, run — under 60 seconds end to end

随机种子固定为 20190810，任何机器上运行都会得到本页展示的同一组数字。

# 1. 克隆仓库
$ git clone https://github.com/lixunnan/typhoon-cat-model.git
$ cd typhoon-cat-model

# 2. 安装依赖（仅 4 个第三方库）
$ pip install -r requirements.txt
#   numpy>=1.24  pandas>=1.5  scipy>=1.10  matplotlib>=3.6

# 3. 运行主流程：12 张图写入 outputs/，终端打印 Executive Summary
$ python main.py

# 4. 单独同步图片到 docs/assets/
$ python sync_docs.py

# 5. 运行 19 项独立校验
$ python tests/test_validation.py
运行耗时

全量流水线实测约 5 秒（含 10,000 场事件模拟、5 个气候情景与 12 张 300 dpi 图渲染），远低于 90 秒目标。

依赖约束

仅 numpy / pandas / scipy / matplotlib 四个第三方库 + Python 标准库，无 cartopy、无 seaborn、无 GIS 依赖。

可复现性
